# Security Policy

## Supported Versions

Security fixes are applied to versions marked **Supported**. Versions marked **Planned** are not released yet.

| Minecraft | Status | Loaders | Latest release | Notes |
|---|---|---|---|---|
| > 1.21.1 | Skipped | n/a | n/a | |
| **1.21.1** | **Supported** | Fabric | `0.1.0-alpha.1` | |
| < 1.21.1 | Skipped | n/a | n/a | |

## Reporting a Vulnerability

Please report vulnerabilities privately through a
[GitHub security advisory](https://github.com/m4idstudios/example/security/advisories/new)
rather than a public issue.

Include the version, Minecraft version, and loader, plus steps to reproduce the stinker if you can.
